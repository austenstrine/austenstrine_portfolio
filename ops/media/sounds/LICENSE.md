## Technical notes

- Generated as mono PCM WAV, then encoded to MPEG-1 Layer III via GStreamer `lamemp3enc`.
- Motif: soft ascending then falling two-syllable chime (~880 Hz → ~660–520 Hz), low amplitude, ~2.8 s period, ~8.4 s file (loop-friendly).
- No trademarked OS notification sounds were copied.
